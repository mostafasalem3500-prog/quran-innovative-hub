# Quran Innovative Hub — منصة توليد بطاقات وفيديوهات القرآن الكريم 4K

استوديو ويب متكامل (Next.js 16 + TypeScript + Tailwind) لإنتاج بطاقات ومقاطع قرآنية معتمدة بدقة تصل إلى 4K، بنمط البث الفضائي لقناة القرآن الكريم.

## المزايا
- **114 سورة** ببيانات ثابتة (عدد الآيات، مكية/مدنية، الاسم الإنجليزي) وبحث فوري.
- **20 قارئاً** (مرتل ومجود) — تلاوة آية بآية مع روابط بديلة تلقائية عند تعذّر جودة معينة.
- **9 تفاسير** عربية: الميسر، الجلالين، السعدي، ابن كثير، الطبري، القرطبي، البغوي، الوسيط، تنوير المقباس.
- **20 لغة ترجمة** (إنجليزي، فرنسي، إسباني، ألماني، أردو، فارسي، إندونيسي، ماليزي، بنغالي، هندي، تاميلي، صيني، سواحلي، هوسا…).
- **محرك رسم سينمائي** (`lib/renderer.ts`): 7 ثيمات، 7 خطوط قرآنية، 4 أبعاد (9:16، 4:5، 1:1، 16:9)، 3 دقّات (HD/2K/4K)، 5 أنماط إطار (منها مزخرف بنجوم ثمانية)، 4 أنماط ترويسة، بسملة تلقائية، شارة رقم الآية، شريط القارئ، سطر التوثيق، علامة مائية، تعتيم/تظليل/ضبابية/توهج، Ken Burns.
- **6 قوالب جاهزة**: بث فضائي، ريلز بسيط، حرمي أخضر، مصحف ورقي، دعوي مترجم، دراسة التفسير.
- **خلفيات**: 10 صور + 4 تدرّجات + رفع صورة/فيديو خاص + رابط مخصص.
- **تصدير**: PNG/JPG/WebP للبطاقة، ZIP لدفعة آيات، **فيديو MP4/WebM بصوت القارئ مدمجاً** (Web Audio + MediaRecorder) مع بطاقة افتتاحية/ختامية، فاصل صامت، تكرار، حركات دخول، شريط تقدم.
- **مشغّل تلاوة**: تلاوة مستمرة، تكرار الآية، مستوى الصوت، سرعة التشغيل، اختصارات لوحة المفاتيح.
- توليد نص المنشور مع الوسوم، رابط مشاركة للآية/النطاق، حفظ الإعدادات تلقائياً + تصدير/استيراد JSON، آية عشوائية، PWA manifest.

## المصادر
| البيانات | المصدر |
|---|---|
| النص العثماني / الإملائي / التراجم | [AlQuran Cloud API](https://alquran.cloud/api) — مصحف المدينة النبوية بترميز Tanzil |
| التلاوات | [Islamic Network CDN](https://cdn.islamic.network) |
| التفاسير الموجزة | AlQuran Cloud (ar.muyassar, ar.jalalayn, ar.qurtubi, ar.baghawi, ar.waseet, ar.miqbas) |
| التفاسير الموسّعة | [tafsir_api](https://github.com/spa5k/tafsir_api) (بيانات QUL — Tarteel) عبر jsDelivr |

## التشغيل
```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## البنية
```
app/page.tsx              الواجهة الرئيسية (تبويبات: الآية / التصميم / الصوت / التصدير)
app/layout.tsx            الخطوط والـ metadata و PWA
components/QuranCanvas.tsx  مكوّن العارض (يدير الخلفية صورة/فيديو ويعرّض دالة draw للتسجيل)
components/ui.tsx         عناصر الواجهة (Section, Toggle, Slider, Segmented, Toasts…)
lib/quranData.ts          طبقة البيانات + الكاش
lib/renderer.ts           محرك الرسم (renderCard) والثيمات والقوالب
lib/exporter.ts           تصدير الصور/ZIP/الفيديو + نص المنشور
```

> ملاحظة: تسجيل الفيديو يتم داخل المتصفح؛ Chrome/Edge الحديثة تُنتج MP4 (H.264/AAC) مباشرة، وغيرها WebM. أبقِ التبويب ظاهراً أثناء التسجيل.
